# Space

Единая среда разработки и персональный AI-инженер «Машенька» на базе Google ADK и моделей Gemini.

## Архитектура
- **Ноутбук (Lenovo T16)**: рабочая станция разработчика (ветка `agent-masha`).
- **GitHub (`korshun199/Space`)**: центральный репозиторий.
- **Боевой VPS (Финляндия)**: сервис круглосуточного доступа на `https://lora.systemio.ru`.

## Структура репозитория
- `my_agent/` — агент Google ADK Машенька (`agent.py`, конфигурация, инструменты терминала и диагностики).
- `auth/` — страница авторизации (`login.html`) с защитой по 4-значному PIN-коду (`0711`).
- `sync.sh` — скрипт автоматической синхронизации ноутбука с GitHub и VPS.
- `setup_adk_service.sh` — развёртывание службы `adk-masha.service` на VPS.
- `setup_auth_nginx.sh` — настройка безопасного виртуального хоста Nginx на VPS.

## Команды разработчика
- **`СИНХРОНИЗИРУЙ`** — запускает `./sync.sh`: фиксирует изменения на ноутбуке, пушит в GitHub и автоматически обновляет репозиторий на VPS.
