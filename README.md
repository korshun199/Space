# Space 🚀

**Space** — распределённый инженерный комплекс и лаборатория управления автономными нодами.

Проект предназначен для консолидации инфраструктуры, автоматизации задач мониторинга, развёртывания сервисов и управления распределённым парком устройств (хост-станции, VPS, контроллеры и одноплатники).

---

## 🪐 Архитектурный контур

Система охватывает несколько ключевых уровней:

1. **Командный центр (Host OS):**
   - Операционная станция Linux (Ubuntu 24.04 LTS).
   - Управление локальной периферией (USB/Serial/UART) и координирование сетевых потоков.

2. **Облачный стенд (Cloud VPS):**
   - Выделенный сервер для круглосуточных сервисов, сбора телеметрии и сетевых туннелей.

3. **Edge-устройства (Одноплатники и контроллеры):**
   - High-performance периферия (**Orange Pi 5** / RK3588) для параллельной обработки данных.
   - Микроконтроллеры и автоматизация (**Raspberry Pi**) для сбора метрик и управления датчиками.

---

## 🛠 Технологический стек

- **OS:** Linux (Ubuntu 24.04 / Debian ARM)
- **Networks:** SSH, WireGuard, VPN, Serial/UART
- **Scripting & Core:** Python 3, Bash, Systemd
- **DevOps & Edge:** Docker, Git, Monitoring utilities

---

## 📜 Лицензия и статус

Проект находится в стадии активной разработки и исследований.  
Все инженерные решения публикуются в виде воспроизводимых конфигураций и исходных скриптов.
